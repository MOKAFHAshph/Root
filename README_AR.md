# بوت ومحفظة USDT — الإصدار 18.2.1

هذا المشروع يوفر واجهتين تعملان على منطق مالي وقاعدة بيانات موحّدة:

- **بوت Telegram كامل** للأوامر السريعة والإشعارات والاستخدام الاحتياطي.
- **Telegram Mini App كاملة** للمستخدم ولوحة الإدارة.

لا توجد محفظتان أو منطقان منفصلان. أي إيداع أو سحب أو تعديل رصيد يظهر في الواجهتين من المصدر نفسه.

## أهم ما تغير في الإصدار 18.2.1

- سعر صرف خاص اختياري لكل عميل؛ مثال: العميل المحدد بسعر 545 وبقية العملاء بالسعر العام 550.
- تثبيت السعر المستخدم داخل العملية منذ تجهيزها، فلا يؤثر تغيير الأدمن على عملية بدأت بالفعل.
- حد أدنى إداري مستقل لكل شبكة، مع تطبيق القيمة الأعلى بينه وبين حد Binance الحي.
- TxID كامل للمستخدم وزر نسخ في رسالة النجاح وسجل Mini App، مع إخفائه جزئيًا في قناة المستخدمين.
- أزرار تعليمية يديرها الأدمن من `/buttons` أو Mini App، مع الاسم والرابط والرمز والحالة والترتيب.
- دعم اختياري لرموز Telegram المتحركة في الأزرار؛ يبقى الرمز العادي بديلًا مضمونًا قبل Premium وبعده.
- حماية الضغط المزدوج على السحب ومنع تداخل فحوص Jaib.
- عرض رقم التحويل الداخلي من Binance كرقم فقط دون عبارة `Off-chain transfer`.
- إبراز الحد الأدنى المتغير للسحب في القائمة الرئيسية وتحديثه من إعداد الشبكة.

## إدارة السعر الخاص للعميل

من البوت افتح العميل من لوحة الأدمن ثم اضغط **تعيين سعر خاص** وأرسل السعر. اضغط **إلغاء السعر الخاص** لإعادته إلى السعر العام.

من Mini App افتح: **الإدارة ← المستخدمون ← تفاصيل العميل ← سعر خاص**. اترك القيمة فارغة لإلغاء التخصيص.

يطبق السعر على العمليات الجديدة فقط. تحفظ كل عملية سعرها عند تجهيزها، لذلك لا يعاد حساب العمليات الجارية أو المكتملة.

## إدارة الحد الأدنى للسحب

- الأمر السريع لشبكة BSC: `/setminwithdraw 10`.
- أو من Mini App: **الإدارة ← الإعدادات ← إدارة الشبكات ← الحد الأدنى**.
- ترك القيمة فارغة يلغي الحد الإداري ويعيد الاعتماد على حد Binance الحي وحده.
- الحد الظاهر والمنفذ للمستخدم هو الأعلى دائمًا بين القيمتين.

## الأزرار التعليمية والرموز المتحركة

1. أرسل `/buttons` من حساب أدمن لديه صلاحية إعدادات المحفظة.
2. اختر **إضافة زر جديد**، ثم أرسل الاسم ورابط HTTPS والرمز العادي.
3. للرمز المتحرك أرسل Custom Emoji نفسه، وسيقرأ البوت معرّفه تلقائيًا. يمكن إرسال المعرّف يدويًا أيضًا.
4. أرسل `-` لتخطي الرمز المتحرك أو مسحه لاحقًا.
5. بعد اشتراك مالك البوت في Premium اضغط **تفعيل بعد اشتراك Premium** داخل `/buttons`. يظل هذا المفتاح متوقفًا افتراضيًا لمنع رفض Telegram للوحة الأزرار قبل الأهلية.
6. استخدم صفحة تفاصيل الزر للتعديل والتفعيل والإيقاف والترتيب والمعاينة.

في Mini App توجد الإدارة تحت: **الإدارة ← الإعدادات ← الأزرار التعليمية**. إدخال الرمز المتحرك هناك يكون بواسطة `Custom Emoji ID`، بينما إرسال الرمز نفسه متاح عبر `/buttons` في البوت. ظهور الرمز المتحرك يخضع لأهلية Telegram وPremium؛ عدم توفره لا يعطل الزر ويظهر الرمز العادي تلقائيًا.

## أهم ما تغير في الإصدار 18.1

- فصل قنوات التشغيل إلى قناة مستخدمين لنجاح السحب فقط، وقناة أدمن خاصة لجميع الأحداث، وقناة مستقلة للنسخ الاحتياطية.
- حذف المستخدم نهائيًا مع كل بياناته حتى عند وجود رصيد، بعد ملخص واضح وتأكيدين منفصلين.
- عرض الرصيد والحد الأدنى الحالي المتغير مباشرة بعد الضغط على زر السحب، دون كشف اسم مزود السيولة.
- إرسال قرار الموافقة أو الرفض من Mini App إلى المستخدم عبر البوت بواسطة صندوق إشعارات دائم.
- فحص اتصال Jaib آمن عند التشغيل وبشكل دوري، مع زر فحص يدوي للأدمن دون تنفيذ عملية مالية.
- تحديث تقارير PDF إلى ألوان Mini App الأحمر والأخضر، وتوحيد مصطلح «الرسوم» في الواجهات.

## أهم ما تغير في الإصدار 18.0

- إصلاح حفظ أرقام Jaib التي تبدأ بصفر، مع عرض القيمة للتأكيد قبل الحفظ.
- إعادة التحقق من رقم العملية تلقائيًا حتى 3 مرات، مع مهلة قابلة للضبط وسجل لكل محاولة.
- إصلاح نشر إشعار السحب الناجح، ومنع التكرار وإعادة الإرسال بعد الانقطاع.
- تشغيل قبول الحسابات يدويًا أو تلقائيًا بعد مدة يحددها الأدمن.
- تعديل بيانات التسجيل حتى القبول النهائي؛ تغيير رقم Jaib بعد التحقق يعيد خطوة التحقق.
- قناة موحدة للإيداعات والسحوبات والطلبات والأخطاء والردود.
- وضع صيانة شامل مع سبب اختياري وتجاوز كامل للأدمن.
- حد تحقق افتراضي 300 YER قابل للتعديل، وعرض YER دون كسور.
- البوت يتحمل 0.01 USDT من الرسم الفعلي لكل سحب.
- إدارة شبكات USDT والعملات من لوحة الأدمن، مع حالة وعنوان ورسم مستقلين.
- إبراز السيولة وتحديث الرسالة الرئيسية وMini App تلقائيًا عند تغيرها.
- تحسين Mini App بميزات Telegram الحديثة: Device Storage، المساحات الآمنة، اختصار الشاشة الرئيسية، إخفاء لوحة المفاتيح، وحماية مسودة السحب عند الإغلاق.

## ميزات الإصدارات السابقة المدمجة

- إضافة **السيولة المتوفرة حاليًا** في واجهتي البوت وMini App دون كشف اسم مزود الصرف للمستخدم.
- خصم احتياطي أمان قابل للضبط من الرصيد المعروض، واحتساب رسوم الشبكة عند التحقق النهائي.
- إضافة حد أقصى لكل عملية سحب يمكن للأدمن تشغيله أو إيقافه وتعديل قيمته.
- إبراز أن الدفع عبر **محفظة جيب (Jaib)** تلقائي وفوري، مع زر لطرق الدفع الأخرى والتواصل مع الإدارة.
- إضافة اسم المستفيد للرقم البديل وسياسة منع التحويل من طرف ثالث وإخلاء المسؤولية.
- إضافة أزرار نسخ سريعة وصفحات نتائج مرئية للنجاح والفشل داخل Mini App.
- إضافة Landing Page للحسابات الجديدة وغير المفعلة مع طلب تفعيل مباشر.
- توحيد مكافأة الإحالة عند التفعيل من البوت أو Mini App ومنع صرفها أكثر من مرة.
- تحديد مهلة قصيرة لقراءة بيانات السيولة في الشاشات الرئيسية حتى لا تتجمد الواجهة عند بطء المزود.
- لم يعد الضغط على زر الإيداع ينشئ عملية مالية في قاعدة البيانات.
- تُنشأ عملية الإيداع عند إرسال رقم العملية فقط.
- التقارير والإحصائيات تعرض النتائج النهائية وحدها:
  - نجاح: `COMPLETED`.
  - فشل نهائي واضح: `REJECTED` أو `FAILED_RELEASED`.
  - لا تُحسب حالات الانتظار أو المعالجة أو الإلغاء.
- أزيل زر **رصيدي** من القائمة لأن الرصيد يظهر في الشاشة الرئيسية.
- تمت إضافة Mini App كاملة للمستخدم والإدارة، وليست صفحة إحصائيات فقط.
- تمت إضافة رموز تأكيد موقعة أحادية الاستخدام لمنع تنفيذ الإيداع أو السحب مرتين.
- أضيف الأمر `/app` وزر دائم لفتح Mini App من قائمة Telegram.
- نُقلت اتصالات Jaib وBinance المتزامنة إلى Threads حتى لا تحجز استجابة البوت.
- أضيف `run_all.py` لتشغيل البوت والـMini App معًا.

## التشغيل السريع

### Windows

```bat
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
copy .env.example .env
python verify_project.py
start_all.bat
```

### Linux / VPS

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
cp .env.example .env
chmod 600 .env
python verify_project.py
./start_all.sh
```

يمكن أيضًا تشغيل الخدمتين منفصلتين:

```bash
python run.py
python webapp_main.py
```

أو معًا:

```bash
python run_all.py
```

## إعدادات التشغيل المهمة

يمكن تعديل القيم التالية في `.env`، ثم التحكم التشغيلي في معظمها من لوحة الأدمن:

```env
PUBLIC_LIQUIDITY_ENABLED_DEFAULT=true
PUBLIC_LIQUIDITY_LABEL=السيولة المتوفرة حالياً
PUBLIC_LIQUIDITY_RESERVE_USDT=1
PUBLIC_LIQUIDITY_CACHE_SECONDS=60
PUBLIC_LIQUIDITY_DECIMALS=2
WITHDRAWAL_OPERATION_LIMIT_ENABLED_DEFAULT=true
WITHDRAWAL_OPERATION_LIMIT_USDT=100
JAIB_SECONDARY_BENEFICIARY_NAME=عبدالرحمن علي
JAIB_REQUEST_TIMEOUT_SECONDS=30
JAIB_HEALTH_CHECK_INTERVAL_SECONDS=60
JAIB_VERIFY_RETRY_ATTEMPTS=3
JAIB_VERIFY_RETRY_DELAY_SECONDS=3
JAIB_API_UTC_OFFSET_HOURS=3
ACCOUNT_VERIFICATION_MAX_YER=300
CHANNEL_USERS=-1000000000001
CHANNEL_ADMIN=-1000000000002
CHANNEL_BACKUP=-1000000000003
```

`PUBLIC_LIQUIDITY_RESERVE_USDT` احتياطي لا يظهر للمستخدم ولا يسمح باعتباره سيولة متاحة. كما يتحقق النظام من رسوم الشبكة قبل اعتماد مبلغ السحب.

## إعداد Mini App

1. استخدم نطاق HTTPS ثابتًا، وليس رابطًا مؤقتًا للاختبار الدائم.
2. ضع الرابط في `MINI_APP_URL`.
3. شغّل `webapp_main.py` خلف Nginx أو Cloudflare Tunnel.
4. أعد تشغيل البوت؛ سيضبط زر القائمة تلقائيًا.
5. يمكن للمستخدم أيضًا إرسال `/app`.

## قاعدة البيانات

SQLite تستخدم:

- WAL.
- Foreign Keys.
- Busy Timeout.
- معاملات ذرية لتغييرات الرصيد.
- Wallet Ledger لتتبع كل حركة.

لا تشغّل أكثر من نسخة Polling للبوت على قاعدة البيانات نفسها. يمكن تشغيل البوت وخادم الويب معًا لأنهما يستخدمان معاملات SQLite، لكن يفضل VPS بقرص محلي سريع.

## تنبيه أمني

- غيّر جميع Tokens وAPI Keys قبل التشغيل الحقيقي.
- لا تشارك ملف `.env`.
- عطّل المفاتيح القديمة بعد انتهاء الاختبار.
- استخدم قيود IP وصلاحيات محدودة لمفاتيح منصات السحب.
- احتفظ بنسخة احتياطية قبل تحديث ملفات الإنتاج.
- لا ترفع ملفات `.db-wal` أو `.db-shm` دون ملف قاعدة البيانات الرئيسي.
